# Your first day

Plan on a relaxed first shift: let Claude do the work and use each step to see how it thinks. Ideally Fatima is reachable by message for the first few hours.

## Before the shift (once)

1. Setup done: README steps 1 to 8, the installer self-test all PASS, FIRST-PROMPT pasted, Claude said "ready".
2. `OPERATOR.md` filled in (name, hours, timezone, end-of-day time, GitHub username).
3. Read, in this order (about an hour): `docs/README.md` (ownership), `01-how-the-job-works.md`, `02-rules.md`, `04-voice-guide.md`, `09-background-machinery.md`, `10-shift-checklists.md`, `11-decision-guide.md`. Skim the `GLOSSARY.md` and the second half of `08-troubleshooting.md` ("Things that go wrong during a shift").
4. Scheduled tasks created (Claude offers this in the first prompt).
5. Windows settings changed (README Step 6b): never sleep when plugged in, lid does nothing, update active hours cover your shift, no automatic lock, Chrome Memory Saver off.

## Hour 1: start and watch

1. Follow the **START OF SHIFT** checklist in `10-shift-checklists.md`.
2. Type `start the routines`.
3. Watch the first sweep. Claude will read the ledger (there are already many items due; that is normal after a handover), open the Trybe tabs, reply to waiting creators, and so on.
4. Its first message has three parts: **Done**, **Needs your go**, **Questions**. For the first day, ask it to explain any item you don't understand: "why do you recommend rejecting 2?"
5. Tip: say "show me the thread" before approving anything you're unsure about. Claude will show what the creator sent.

## Hours 2 to 3: learn the decisions

- **Videos (submissions):** ask Claude to show you the frames and the reason for each verdict, against the 6-point checklist. After a few, you'll spot the common problems yourself: seat not under the bottom, a hand coming off baby, buckle loop unused, a sale-led opening.
- **Applicants:** look at one or two applicant videos with Claude's verdict. The rule is simply "can we see them talking to camera, confidently, with a clear English accent?".
- **Samples:** Claude approves eligible ones on its own and tells you after. Read one approval message it sent.

## Hours 4 onward: settle in

- Answer each sweep's message in one go ("yes 1 and 3, no 2").
- If Claude drafts inspo messages, read them: they go to you before sending until you say they can go straight out.
- If a creator asks about **money, retainers or commission**, or it involves one of the **10 protected creators**, ask Fatima.
- If a message sounds off to you, tell Claude why. It records the lesson in the voice guide.

## End of shift

Follow the **END OF SHIFT** checklist. Check the wrap-up message says "Pushed". Forward any Liam links on Slack.

## Things that are normal (don't worry)

- The Discovery badge never reaches zero.
- The Discovery page freezes sometimes.
- Claude re-reads a thread right before sending, even if it read it a minute ago.
- Claude refuses to send when the creator's newest message isn't answered yet; that is a safety guard.
- Many ledger items come due at once after a break.

## Things to never do

- Paste the Trybe key (or any password) into the Claude chat.
- Minimise the Chrome window Claude is using, or close its `cl=` tabs.
- Open Claude Code in a folder other than `Bombara`.
- Run two "start the routines" chats at once, or run the routine while Fatima runs hers on her Mac.
- Tell a creator about the handover.
- Make the GitHub repo public.
