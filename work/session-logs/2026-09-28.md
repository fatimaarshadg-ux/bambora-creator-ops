## Machine setup fixed (four real breakages)

1. **`py` was missing from PATH**, so the follow-up ledger and the helper server both failed with
   nothing useful printed. `start.ps1` now resolves `py.exe` by full path when `Get-Command py`
   misses, and ignores the Git Bash shim, which PowerShell cannot execute.
2. **The helper server was single-threaded** (`socketserver.TCPServer`). One stalled connection
   blocked every later request, so a 2 ms fetch took over 2 minutes and Chrome could not load the
   sweep scripts. Rewritten on `ThreadingHTTPServer` with daemon threads, and the served folder is
   pinned to the file's own directory. Verified with six concurrent requests.
3. **The PC clock is US Pacific, not Pakistan time.** Cron fires on local time, so the 6:12 AM PKT
   end-of-day job had to be scheduled as `12 18 * * *`. The send window was never at risk because
   `us-time.ps1` computes US Eastern itself.
4. **`tt.py` called `yt-dlp` by bare name** and died with an unreadable `WinError 2`. It now falls
   back to the copy inside the media watcher.

Also found: a **second clone of the repo at `D:\Projects\bambora-creator-ops`**, unused and not
wired to anything. Both clones push to the same single GitHub repo. Ikra asked to keep only one up
to date, so the C copy is the live one. Deleting the D copy is still awaiting her yes.
