The brand is spelled **Bambora**, website https://bamboraco.com (baby carriers),
positioned "Made by Parents. Loved by Parents." The local folder is
`~/Bombara`, which is a misspelling; use "Bambora" in anything
customer- or team-facing.

Brand palette sampled from the live site, for decks and other collateral:
- Ink / foreground `#2E2A39` (deep aubergine)
- Signature soft blue `#B7CCDF` (buttons, links)
- Deep blue `#343D52`, off-white `#F6F6F6`, white
- Site font is Poppins (not present in PowerPoint, so Calibri/Arial substitute)

Creators are managed through Trybe (see the `trybe` MCP server and the
`trybe-review` folder). Related: [[bambora-creator-strategy-deck]]
