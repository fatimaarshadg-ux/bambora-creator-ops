On 2026-09-24 the grandparent yapper-check folder (scripts, transcripts, per-creator verdicts) was pushed to claude-setup and Fatima said it "didn't need to go in github". It was removed from the repo and kept locally.

**Why:** the sync repo is for things she reuses on both machines (skills, memory, templates, tools), not per-task working data.

**How to apply:** keep one-off breakdowns, vetting lists and scratch outputs local. Push only reusable scripts or docs she will want again, and when unsure, ask in one line before pushing. Related: [[bambora-grandparents-program]].
